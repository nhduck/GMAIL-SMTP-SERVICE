Tích Hợp Dịch Vụ Vào Ứng Dụng Khác

Các hệ thống ứng dụng trong kiến trúc SOA gọi Email Gateway thông qua các endpoint REST API chuẩn:

1. Xác thực tài khoản (Account Verification)

// Gọi API xác thực tài khoản (Live mode bắt buộc truyền otp hoặc verifyUrl; Sandbox có thể bỏ trống để tự sinh)
await fetch("http://localhost:3000/api/v1/verify-email", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    to: "student@tdtu.edu.vn",
    name: "Nguyễn Văn A",
    otp: "123456" // Ứng dụng nghiệp vụ tự sinh OTP để lưu DB
  })
});

2. Đặt lại mật khẩu (Password Reset)

// Gửi link đặt lại mật khẩu với thời hạn an toàn 5 phút (mặc định)
await fetch("http://localhost:3000/api/v1/password-reset", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    to: "student@tdtu.edu.vn",
    name: "Nguyễn Văn A",
    resetUrl: "https://myapp.com/reset-password?token=sec_abc123"
  })
});

3. Gửi HTML Email theo Mẫu (HTML Email Template)

curl -X POST http://localhost:3000/api/v1/send \
  -H "Content-Type: application/json" \
  -d '{"to": "dev@tdtu.edu.vn", "template": "custom-html", "variables": {"title": "Chào mừng!", "content": "
Nội dung HTML
"}}'

Tính năng mở rộng: Nhúng Web Component (HTML)

<script src="http://localhost:3000/embed.js"></script>
<mail-widget target="admin@cuahang.com" title="Liên Hệ"></mail-widget>
