Tích Hợp 1 Dòng Vào Dự Án Khác (Developer Experience)

Mọi dự án Web/Backend chỉ cần copy 1 trong các đoạn mã sau là dùng được ngay:

1. Web Component (Chuẩn 1 dòng như Bootstrap - HTML thuần)

<!-- Dán vào thẻ <head> hoặc <body> -->
<script src="http://localhost:3000/embed.js"></script>
<mail-widget target="admin@mydomain.com" title="Liên Hệ Với Chúng Tôi"></mail-widget>

2. JavaScript SDK (Dành cho React/Vue/Frontend SPA)

<script src="http://localhost:3000/mail-agent.min.js"></script>
<script>
  MailAgent.send({
    to: "customer@gmail.com",
    subject: "Mã OTP",
    html: "<b>123456</b>"
  });
</script>

3. REST API / cURL (Dành cho Backend Node, Python, Java, PHP)

curl -X POST http://localhost:3000/api/v1/send \
  -H "Content-Type: application/json" \
  -d '{"to": "dev@example.com", "subject": "Test", "html": "Hello SOA"}'
