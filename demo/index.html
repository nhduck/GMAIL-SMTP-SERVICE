Sample Client Application (Mô Phỏng Ứng Dụng Môn Học)

Ứng Dụng Mẫu: Đăng Ký & Đặt Lại Mật Khẩu

Minh họa cách một dự án sinh viên khác tích hợp Email Gateway chỉ bằng vài dòng JavaScript gọi API.

Mã Nguồn Tích Hợp (6 Dòng Code) ● REST API 
// 1. Gọi Email Gateway gửi mã xác thực
await fetch("http://localhost:3000/api/v1/verify-email", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    to: "student@tdtu.edu.vn",
    name: "Nguyễn Văn A"
  })
});
💡 Mẹo kiểm thử: Ở chế độ Sandbox, mở trang Dashboard Quản Trị để xem email và mã OTP nhảy lên màn hình ngay tức thì!
